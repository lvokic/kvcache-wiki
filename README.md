# LLM Wiki

This repository is a personal knowledge base maintained by an LLM, currently focused on KV-cache management and LLM serving systems. The owner curates source files in `raw/`; the LLM builds and maintains the linked Markdown wiki in `wiki/`.

## Getting started

1. Agree on the wiki's subject and scope.
2. Add source files under `raw/` and ask the LLM to ingest them one at a time or in a batch.
3. Review summaries, citations, and updates in `wiki/`.
4. Ask questions against the wiki, or request a lint pass as it grows.

See [AGENTS.md](AGENTS.md) for the operating rules, and start with [the wiki index](wiki/index.md).
